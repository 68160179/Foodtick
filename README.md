# FOOD TRICKS — เว็บแชร์สูตรอาหาร

เว็บแชร์สูตรอาหารสไตล์ Lemon8 (ฟีดรูปแบบการ์ด 2–4 คอลัมน์) ดีไซน์มินิมอล โทนขาว/ครีม เขียนด้วย PHP + MySQL (mysqli + prepared statements)

## ฟีเจอร์
- สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ (`register.php`, `login.php`, `logout.php`) — รหัสผ่านเก็บด้วย `password_hash`
- หน้าแรกเป็นฟีดการ์ด + แถบเลือกประเภท (`index.php?cat=...`)
- หน้าหมวดหมู่ (`categories.php`): ทอด, นึ่ง, ต้ม, ผัด, ตุ๋น, ย่าง, ปิ้ง, อบ, แกง, ยำ/สลัด, ของหวาน, เครื่องดื่ม
- หน้าค้นหา (`search.php`) ค้นจากชื่อเมนู คำบรรยาย หรือวัตถุดิบ กรองตามหมวดได้
- กดรูปแล้วเข้าโพสต์ (`recipe.php?id=`) : รูปอาหาร แล้วด้านล่างเป็น 2 ช่อง ① วัตถุดิบ + ปริมาณ ② วิธีการทำ
- สมาชิกโพสต์สูตรเองได้ (`recipe_new.php`) : ① รูปอาหารที่ทำ ② วัตถุดิบ ③ สูตร/วิธีทำ แก้ไขและลบสูตรของตัวเองได้
- **ร่าง (แบบ TikTok):** กด “บันทึกร่าง” เก็บไว้ก่อน ยังไม่ต้องใส่รูปหรือกรอกให้ครบ ร่างมีแค่เจ้าของที่เห็น กลับมาแก้แล้วกด “โพสต์” วันหลังได้ (ตอนโพสต์ สูตรจะขึ้นบนสุดของฟีด)
- **กดใจ และบันทึกลงคลัง** ในหน้าโพสต์ กดแล้วอัปเดตทันทีไม่ต้องโหลดหน้าใหม่ (`toggle.php`)
- **คอมเมนต์** ใต้โพสต์ (`comment.php`) ลบได้ทั้งคนเขียนคอมเมนต์และเจ้าของโพสต์
- **แก้ไขโปรไฟล์** (`profile_edit.php`): รูปโปรไฟล์, ชื่อที่แสดง, คำแนะนำตัว, เปลี่ยนรหัสผ่าน
- ปุ่มลบ (สูตร / ร่าง / คอมเมนต์) ถามยืนยันด้วยกล่องในหน้าเว็บ ไม่ใช้ `confirm()` ของเบราว์เซอร์ ซึ่งบางเบราว์เซอร์บล็อกไว้จนกดลบไม่ได้
- หน้าโปรไฟล์ (`profile.php`) มีแท็บ โพสต์ / ร่าง / คลัง / ถูกใจ (3 แท็บหลังเห็นได้แค่เจ้าของ เหมือน TikTok)
- **ไม่มีข้อมูลตัวอย่าง** — ถ้ายังไม่มีใครโพสต์ หน้าเว็บจะว่าง (มีแค่ข้อความชวนโพสต์)

## ติดตั้ง
1. นำเข้า `database/setup.sql` ใน phpMyAdmin (สร้างฐานข้อมูล `halloween_food` + ตาราง + หมวดหมู่)
   - บน Angsila: ลบบรรทัด `CREATE DATABASE` และ `USE` ออกก่อน แล้วเลือกฐานข้อมูลของตัวเองแล้วค่อย Import
   - **เคย import รุ่นแรกไปแล้วและมีข้อมูลอยู่:** ไม่ต้องรัน `setup.sql` ใหม่ (มันจะลบข้อมูลทิ้ง) ให้ import ไฟล์ migrate ตามลำดับแทน: `database/migrate_v2.sql` (ร่าง/กดใจ/คลัง/คอมเมนต์) แล้ว `database/migrate_v3.sql` (รูปโปรไฟล์/แนะนำตัว)
2. คัดลอก `config/db.local.example.php` เป็น `config/db.local.php` แล้วใส่ host / user / password / ชื่อ DB (ไฟล์นี้ถูก `.gitignore` ไว้ ไม่ขึ้น GitHub)
3. ให้โฟลเดอร์ `uploads/` เขียนได้ (บนเซิร์ฟเวอร์ลินุกซ์: `chmod 777 uploads` หรือ 775 ถ้ากลุ่มตรงกับ web server)
4. เปิด `http://localhost/พี่เต้/`

## ตารางในฐานข้อมูล
| ตาราง | เก็บอะไร |
|---|---|
| `app_user` | สมาชิก (username, ชื่อที่แสดง, รหัสผ่านที่ hash แล้ว, รูปโปรไฟล์, คำแนะนำตัว) |
| `category` | ประเภทอาหาร |
| `recipe` | โพสต์สูตร (เจ้าของ, ประเภท, ชื่อเมนู, คำบรรยาย, path รูป, สถานะ `draft`/`published`) |
| `recipe_ingredient` | วัตถุดิบ + ปริมาณ ของแต่ละสูตร |
| `recipe_step` | ขั้นตอนวิธีทำ ของแต่ละสูตร |
| `recipe_like` | ใครกดใจสูตรไหน (1 คนกดได้ 1 ครั้งต่อสูตร) |
| `recipe_save` | สูตรที่แต่ละคนบันทึกลงคลัง |
| `recipe_comment` | คอมเมนต์ในโพสต์ |

## ความปลอดภัย
prepared statements ทุก query, `htmlspecialchars` ทุกจุดที่แสดงผล, CSRF token ทุกฟอร์ม POST, ตรวจไฟล์รูปด้วย `getimagesize` และตั้งชื่อไฟล์ใหม่แบบสุ่ม, ลบได้เฉพาะสูตรของตัวเอง (`WHERE id = ? AND user_id = ?`)
